# 📈 Financial AI Agent — MVP

منصة تحليل الأخبار اللحظية بالذكاء الاصطناعي وتوجيه المتداول. هذا الإصدار (MVP) قابل للتشغيل فوراً، ومبني بحيث يسهل توسيعه لاحقاً نحو الميزات المتقدمة.

---

## 🚀 التشغيل خطوة بخطوة

### 1. تثبيت المتطلبات
```bash
python -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. إعداد المفاتيح
انسخ `.env.example` إلى `.env` وعبّئ مفاتيحك:
```bash
cp .env.example .env
```
- **Finnhub** (مجاني): سجّل من https://finnhub.io/register — يعطيك الأخبار وبيانات الشركات.
- **OpenAI**: من https://platform.openai.com/api-keys — لتحليل الأخبار وتوليد خطة التداول.
- **Telegram** (اختياري): أنشئ بوت عبر `@BotFather` في تلغرام، واحصل على `chat_id` عبر إرسال رسالة للبوت ثم زيارة:
  `https://api.telegram.org/bot<TOKEN>/getUpdates`

يمكنك أيضاً إدخال المفاتيح مباشرة من الشريط الجانبي داخل التطبيق دون الحاجة لملف `.env`.

### 3. تشغيل التطبيق
```bash
streamlit run app.py
```
سيفتح المتصفح تلقائياً على `http://localhost:8501`.

### ⚠️ حدود مهمة يجب معرفتها
- **حدود Finnhub المجانية**: مراقبة 15 سهماً كل دقيقة يعني عدد طلبات كبير — إذا واجهت خطأ "Rate Limit"، قلّل عدد الرموز أو زد الفاصل الزمني.
- **تكلفة OpenAI**: تفعيل "التحليل التلقائي بالذكاء الاصطناعي" يعني استهلاك رصيدك تلقائياً مع كل خبر قوي جديد، بدون تدخل منك — راقب استهلاكك من لوحة تحكم OpenAI.
- **قاعدة بيانات التوصيات مؤقتة إذا نشرت التطبيق سحابياً**: على Streamlit Community Cloud تحديداً، ملف `finai.db` قد يُمسح عند أي إعادة تشغيل للتطبيق (لا يوجد تخزين دائم في الخطة المجانية).
- **الأسهم الأكثر ربحاً**: تعتمد على نقطة بيانات غير موثّقة من ياهو، ممكن تتغيّر أو تتوقف دون إشعار.
- **مدة الصفقة التقديرية**: تخمين استرشادي من الذكاء الاصطناعي بناءً على نوع الخبر، وليس تنبؤاً مضموناً.

### 👥 لإضافة مستخدم جديد
```bash
python generate_password.py
```
انسخ الـ hash الناتج والصقه في `auth_config.yaml` تحت اسم مستخدم جديد (فيه مثال جاهز داخل الملف).

## ✅ ما يغطيه هذا الإصدار (MVP)

1. **الأخبار اللحظية** عبر Finnhub (عامة + حسب السهم).
2. **تصنيف أولي سريع** للأخبار (High/Low Impact) بالكلمات المفتاحية — مجاني وفوري، بدون استهلاك رصيد AI.
3. **تحليل عميق بالذكاء الاصطناعي** لكل خبر يختاره المستخدم: تلخيص + معنويات + مستوى تأثير + نسبة ثقة + تقييم مصداقية المصدر + خطة تداول (دخول/وقف خسارة/هدف/شرط خروج).
4. **بيانات السهم اللحظية** عبر `yfinance`: السعر، التغير %، القيمة السوقية، القطاع، حجم التداول.
5. **فحص Short Squeeze**: Float + نسبة الشورت من الفلوت.
6. **شارت TradingView تفاعلي** مدمج مع RSI/MACD/المتوسطات المتحركة.
7. **حاسبة إدارة المخاطر وحجم الصفقة** (Position Sizer) الكاملة كما طلبت.
8. **قائمة متابعة سريعة** متعددة الأسهم.
9. **تنبيهات تلغرام** عند رصد خبر عالي التأثير (تصنيف أولي).
10. واجهة عربية كاملة، بسيطة وواضحة.

## 🛣️ خارطة الطريق للميزات المتقدمة (المرحلة القادمة)

الميزات التالية التي ذكرتها في طلبك **تحتاج بنية تحتية إضافية** (خوادم دائمة التشغيل، اشتراكات بيانات مدفوعة، أو WebSockets) ولذلك لم تُدرج في الـ MVP لتبقى قابلة للتشغيل الفوري. إليك كيف تُبنى كل واحدة تباعاً:

### 1. تنبيهات لحظية عبر WebSockets (بدل التحديث اليدوي)
- استبدل `requests` بجلسة WebSocket دائمة مع Finnhub (`wss://ws.finnhub.io`).
- شغّلها في عملية خلفية منفصلة (`asyncio` + `websockets`) تكتب النتائج في قاعدة بيانات (Redis/SQLite)، والواجهة تقرأ منها كل بضع ثوانٍ (`st.autorefresh`).

### 2. تحليل المنتديات ومواقع التواصل (Reddit/X)
- Reddit: مكتبة `praw` (تحتاج تسجيل تطبيق على Reddit API).
- X (تويتر): API الرسمي مدفوع الآن غالباً؛ البديل الشائع هو خدمات طرف ثالث لرصد الترند.
- تُحسب نسبة الذكر (mentions) لكل رمز سهم خلال ساعة/يوم، وتُعرض كمؤشر "Social Hype Score".

### 3. مؤشر الخوف والجشع + المؤسسات والمطلعين (Insiders)
- Fear & Greed: يمكن سحبه من مصادر عامة (مثل CNN Fear & Greed عبر scraping غير رسمي، أو بدائل مدفوعة أدق).
- Insider Trading: بيانات SEC Form 4 متاحة مجاناً عبر EDGAR API (`https://www.sec.gov/cgi-bin/browse-edgar`).

### 4. تحليل التقارير المالية (10-K/10-Q) والـ Backtesting
- استخدم SEC EDGAR لجلب التقارير، ثم مرّرها لنموذج AI بسياق طويل (أو استخراج الأرقام أولاً عبر Regex/pandas قبل إرسالها للنموذج لتوفير التكلفة).
- الـ Backtesting: تحتاج قاعدة بيانات تاريخية للأخبار + الأسعار (Polygon.io يوفر هذا مدفوعاً)، ثم محاكاة الدخول/الخروج حسب استراتيجيتك وحساب نسبة الربح التاريخية.

### 5. Options Flow والتقلب الضمني
- تحتاج مزود بيانات خيارات مثل Polygon.io أو Tradier أو CBOE DataShop (غالباً مدفوعة).
- تُحسب "الحركة المتوقعة" (Implied Move) من سعر خيار ATM (At The Money) القريب من تاريخ الاستحقاق.

### 6. بيانات بديلة (Web Traffic، الوظائف)
- Web Traffic: خدمات مثل SimilarWeb API (مدفوعة).
- الوظائف المفتوحة: يمكن جلبها من صفحات "Careers" للشركات أو مزودين مثل LinkUp/Revelio (مدفوعة).

### 7. Paper Trading وسجل أداء AI
- أسهل طريقة: جدول SQLite/PostgreSQL يسجل كل توصية (رمز، تاريخ، سعر دخول، وقف، هدف)، ثم Cron Job يومي يقارن السعر الحالي بالتوصية ويحدّث الحالة (رابحة/خاسرة/مفتوحة)، وتُعرض إحصائيات النجاح كنسبة مئوية على لوحة تحكم منفصلة.
